rus Откройте командную строку от имени администратора.
Введите команду: cd C:\Program Files (x86)\EasyAntiCheat_EOS (путь может отличаться в зависимости от установки).
Затем введите: EasyAntiCheat_EOS.exe repair.
Чтобы проверить результат, введите: echo %ERRORLEVEL%. Если увидите 0, ремонт прошёл успешно. Если что-то другое — попробуйте ещё раз, убедившись, что командная строка запущена от имени администратора.
